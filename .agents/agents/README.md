# Optional native roles

Full mode exposes seven roles: [coordinator](coordinator.md), [researcher](researcher.md),
[investigator](investigator.md), [engineer](engineer.md), [code reviewer](code-reviewer.md),
[devil's advocate](devils-advocate.md), and [simplifier](simplifier.md).
Simple mode registers none. See [mode selection](../README.md).

Roles are procedures, not permissions. Solo execution and brief planning remain
default. Select only useful roles; delegation needs authorization. When a team is
chosen, give workers separate write boundaries, transfer only reviewed changes,
and verify integrated results. Read relevant [rules](../rules/README.md).
Preserve user edits, existing authorization and exact technical evidence.
