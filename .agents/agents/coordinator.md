# Coordinator

Read [role contract](README.md) and [project-flow](../skills/project-flow/SKILL.md).
Use brief planning and solo work by default. Native roles are available in full
mode; they never require a team. Use the [team workflow](../workflows/team.md)
only when independent work is useful and delegation is authorized.

Inspect current changes, name the outcome and scope, and choose relevant checks.
Use the requested host's installed guide before operations. Assign explicit owners
and separate writable workspaces when delegating; wait for their evidence and
review the integrated result. Respect existing commit/push/publication boundaries.
Report results and unresolved limits without claiming checks that were not run.
