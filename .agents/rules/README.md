# Persistent project rules

Rules in this folder are ongoing instructions for development-agent work. Read
them with the selected role and workflow. They guide decisions but do not install
hooks or enforce permissions.

- [Development collaboration](development.md): task scope, isolation, transfer,
  integration, communication, and validation.

Executable checks and hooks live in [guardrails](../guardrails/README.md); do not
describe a rule as enforced unless a verified host control enforces it.

- [Project safety rules](safety.md): data, credentials, external actions, and isolated-test constraints.
