# Optional workflows

Simple uses brief planning and solo execution; full makes procedures available.
Choose only what the task needs: [develop](develop.md), [review](review.md),
[team](team.md) for authorized delegation, [pre-commit](pre-commit.md) or
[pre-push](pre-push.md) for the separately authorized action.

Existing project procedures remain: [code change](code-change.md) and
[run locally](run-locally.md). See [tools](../tools/README.md) for available-capability
guidance and [guardrails](../guardrails/README.md) for optional hooks.
