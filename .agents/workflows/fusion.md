# Fusion protocol

Give participants identical requests, evidence and read-only scope.
Collect independent proposals before exposing peer answers. Use anonymous seat labels
when supported; retain the model mapping in audit artifacts. Freeze proposals, then
collect critiques of tradeoffs and gaps. Synthesize one complete plan preserving
dissent, assumptions and unresolved user decisions. Pin the exact plan by hash.
Collect independent votes without revealing live ballots or silently dropping seats.
Accept only if all required voters approve that exact plan with no blocker.
Otherwise revise within the round/cost budget or stop and report dissent.
Agreement proves neither implementation correctness nor external-action authorization.
