# Develop

Read [project-flow](../skills/project-flow/SKILL.md) and relevant project rules.
Inspect existing edits, identify the requested outcome and owned paths, then make
the smallest complete change. Brief planning and solo work are defaults.

Full mode offers optional [roles](../agents/README.md) and procedures when useful;
it does not require a team, SpecsMD or Council. Delegate only when authorized.
Use meaningful checks for changed behavior and report evidence and limits.
Commit and push remain separately authorized actions.
