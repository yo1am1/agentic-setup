# Run the consuming project locally

1. Read the project's root and component-specific instructions and README.
2. Use its documented setup and startup commands. Keep existing local settings;
   do not replace credentials or copy another project's environment files.
3. Prefer isolated fixtures or the project's documented demo mode. Verify that
   the selected configuration cannot write to live services or spend credits.
4. Check process readiness separately from upstream connectivity and user flows.
5. Record commands, observed results, and limits. Stop only processes started
   for this task, preserving user-owned services and data.
