# Experiments

Autoresearch experiments: each folder has `program.md` (spec), `train.py` (run script),
`configs/` (one YAML per run), `results.tsv` (run ledger), `logs/`.

Status column in results.tsv: `keep` (tied or beat champion) | `discard` | `crash`.

## Layout

```
<name>/   <One sentence>. Metric: <primary> (<higher|lower> better).
```
